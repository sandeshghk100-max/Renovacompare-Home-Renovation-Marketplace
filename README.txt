RENOVACOMPARE — HOME RENOVATION CONTRACTOR MARKETPLACE

RUN THE WEBSITE
1. Extract the ZIP file.
2. Open the renovacompare-website folder.
3. Double-click index.html (or right-click > Open with Chrome/Edge).
4. On the welcome screen, choose Continue as Guest to enter immediately.

FEATURES
- Sign in / create-account demo screen and Continue as Guest
- Homeowner dashboard and project statistics
- Create and search renovation projects
- Browse and filter contractor profiles
- Request a quote (demo interaction)
- View proposal details and compare price, materials, scope and timeline
- Select a contractor and update project status
- Responsive layout for desktop, tablet and mobile
- Demo project data saved in browser localStorage

IMPORTANT
This is a self-contained front-end prototype. Sign-in, quote requests and contractor profiles are demo-only; no real account authentication, server, database, email delivery, or live contractor verification is connected. Data is stored only in the browser used to open the website. Images and fonts load from external services and require an internet connection.
